Kodi add-on repository

Arsath Jabbar Kodi Add-ons

Install the repository in Kodi to browse and install its available add-ons.

Download Kodi repository ZIP

Download the ZIP to your Kodi device. Keep it zipped; Kodi installs it directly.

Install in Kodi

  1. In Kodi, open Settings → System → Add-ons and enable Unknown sources.
  2. Open Add-ons → Add-on browser → Install from zip file.
  3. Select repository.arsathjabbar-1.0.0.zip and confirm the prompt.
  4. When installation finishes, choose Install from repository → Arsath Jabbar Kodi Add-ons.
